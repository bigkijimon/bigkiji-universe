# Claude Code履歴をBKUへ引き継ぐ

原本を保持したまま、機械抽出はローカル、判断と検収は上位モデル、成果物のQAは別視点で行う。

## 絶対ルール

- `~/.claude/projects/**/*.jsonl` は `claude --resume` の正本。移動・改名・削除・書換えをしない。
- 生ログ全体をモデルへ渡さない。まず `scripts/audit-claude-history.js` で無料の決定論的抽出を行う。
- 最終発言が「待っています」「コミットします」でも未完了とは限らない。後続セッション、Git、成果物、本番を照合する。
- セッション上限、`/compact`、`[Request interrupted]` は停止理由であって作業状態ではない。
- 秘密・メール・電話は抽出時にBKUのredactorで伏せる。生ログをPi知識へ複製しない。
- BKUの目的は **課金トークンの節約と成果物品質の上昇の両方**。片方だけならBKUを使ったことにしない。

## 手順

1. 最近の候補をローカル抽出する。

   ```bash
   node skills/claude-history-recovery/scripts/audit-claude-history.js --since 2026-08-15 --format markdown
   ```

2. 各候補を次の5区分で人が判定する。

   - `OPEN` — ユーザーの依頼に対する成果物・QA・反映のどれかが残る。
   - `DONE` — Git・成果物・本番など客観証拠で完了している。
   - `SUPERSEDED` — 後続セッションや別エージェントが同じ依頼を完了した。
   - `STOPPED` — ユーザーが明示的に中止・保留した。
   - `TEST` — 実運用に戻してはいけない検証用セッション。

3. `OPEN` だけを、元のcwd、最後の実指示、現在の実ファイル、完了条件、禁止事項つきで引継ぎ台帳へ書く。推測した残作業は事実と分ける。
4. 保存先を分ける。

   - 再利用可能な判断・失敗パターン → `/Users/yuma/Documents/.bku/knowledge/`
   - 今回の監査結果・再開キュー → `/Users/yuma/BigKijiUniverse/reports/`
   - 案件固有の途中成果 → 元案件内。既存の `.bigkiji/handoff/<runId>/` があればそこを正本にし、勝手な第二正本を作らない。
   - 反復可能な操作手順・スクリプト → このSkill。
   - 秘密、`.env`、顧客原本、生ログ → 上記のどこにも複製しない。

5. BKUで再開するときは機械作業をローカル/Qwenへ、設計・修正判断を適切な専門モデルへ振り、最後に別視点QAを通す。

## 品質ゲート

完了条件は「ファイルを書いた」ではない。

- コード: diff確認、型・lint・対象テスト、必要ならbuild、Git状態。
- 本番: デプロイ状態だけでなく公開URLの実物確認。
- PDF/教材: 現行ソースから再生成、ページ寸法・文字抽出・画像化した目視、作成者と別視点のQA。
- QA指摘: 修正後に再生成して再QA。古いPDF・古いスクリーンショットを検品しない。
- 外部事実が必要な箇所: 仮の値で埋めず、`OWNER_INPUT_REQUIRED` として分離する。

今回の履歴で、機械照合合格後に第三者QAが33件（CRITICAL 3 / MAJOR 13 / MINOR 17）を発見した。したがって機械検査だけを品質保証として扱わない。

## トークン節約ゲート

- ファイル列挙、JSONL抽出、重複排除、件数・hash・Git照合はスクリプトで行う。
- 大量翻訳・分類はGPU信号を確認してローカルモデルへ回し、行IDと許容範囲を固定する。
- ローカル出力は上書き範囲を検証してから採用する。範囲外ID、欠番、1行ずれを自動検査する。
- 上位モデルには、抽出済み候補と証拠だけを渡す。同じ履歴を何度も要約し直さない。

## 罠

- Qwenの翻訳結果を番号だけでmergeすると、範囲外IDが正しい既存訳を上書きする。バッチごとに許可ID集合を検証する。
- HTMLタグで分断された文章をノード単位で翻訳すると文が壊れる。文章を組み立ててから翻訳し、元の構造へ戻す。
- QA中にソースを変更したら、そのQA対象は古い。必ず再生成してから再QAする。
- Git cleanでも依頼完了とは限らない。未push、未deploy、外部入力待ちを別々に確認する。
- 古い履歴のcwdが移転前（例: 廃止済みの `CEOBigKiji` 配下）なら、そのcwdでresumeしない。`folder-layout-2026-08-09.md` で現行の正本を解決してから、現行Gitと実運用を監査する。
