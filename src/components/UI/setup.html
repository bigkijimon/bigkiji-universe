How should the existing data move?

—

Move the files recommended
A real relocation, so the old locations are genuinely empty afterwards. Each item is verified byte-for-byte before the original is removed, and the whole operation can be rolled back.
Leave everything where it is
Nothing moves. BigKiji just records where each folder already lives. Safest, but the old scattered layout stays.
The text-to-speech engine is a Python virtualenv, which stores absolute paths internally. Moving it will break speech until the virtualenv is re-created at the new location.
